# 🎨 Color Detection using OpenCV

## 📌 Description
This project detects basic colors (Red, Green, Blue) using a webcam.
It uses OpenCV to process video frames and draw rectangles around detected colors.

## 🧠 How it works
1. Capture video from the camera
2. Convert the image to HSV color space
3. Define color ranges (Red, Green, Blue)
4. Create masks for each color
5. Detect contours and draw rectangles

## 🛠️ Tools Used
- Python
- OpenCV
- NumPy

## ▶️ How to Run
1. Install libraries:
pip install opencv-python numpy

2. Run the code:
python main.py
